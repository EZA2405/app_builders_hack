BIslandInspired by Vorssaint · black top-edge island · corner-bracket targets · dark-first
BESIDE · ISLAND SYSTEM
The island tells. The corners point.
Instructions always appear in one place: a solid black island hanging from the top edge, so there's one spot to look. The target gets four blue corner marks and a small number tag. Solid black is readable over anything, so the card doesn't need to adapt to what's behind it.

01
The island always hangs from the top center. It's one place to look, every time.
02
If the island would cover the target, it shrinks to Compact. If it still overlaps, it slides to the opposite top corner.
03
The tag repeats the key word from the island, which links the instruction to the spot on screen.
