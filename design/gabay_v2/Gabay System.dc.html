CARD SPEC
Size. Width fits the sentence, max 440pt (560 when stuck). Padding 18 / 22. Gap 6 between lines, 10 above actions. Content. One sentence, key word bold. A second line only when it helps find the target. Actions only on hover or after 8 s without progress. Placement. Try below, right, left, then above. 20–22pt from the target, with a 12pt popover arrow pointing at the ring (like NSPopover). Keep-out: target + 24pt, any open menu, the box being typed in, the screen edge + 8pt. Busy backgrounds. If the area behind the card has dense text or strong contrast, raise the tint to 0.7 white (dark: 0.6 black) so the glass reads as solid. Dark backgrounds. The card follows system appearance, not the content behind it. The 0.5pt hairline keeps its edge visible on black. Clicks. The ring layer ignores the mouse. The card window takes clicks only on its own buttons; everything else passes through.
